# 推广素材与发布计划

本文档用于统一 GitHub、Gitee 和社区渠道的项目介绍。发布前请用最新版本重新核对功能描述和下载链接。

## 一句话介绍

安全优先的 Windows C 盘清理工具：先解释数据用途，再由用户决定是否删除，支持 AppData 精确扫描。

## 短介绍

C 盘清理助手是一款开源、免安装的 Windows 10/11 磁盘清理工具。它不会默认勾选清理项，而是逐项解释数据用途和删除影响；支持 AppData 快速估算、精确扫描、资源管理器定位和多重删除确认，系统目录受到硬性保护。

## 通用发布正文

Windows 用久以后，C 盘经常被 AppData、浏览器缓存、崩溃日志和开发工具缓存占满。真正麻烦的不是找到大目录，而是不知道它有什么作用、删掉会发生什么。

因此我做了“C 盘清理助手”：扫描后先说明每类数据的来源、用途和删除影响，再由用户自己勾选。所有项目默认不勾选；系统目录禁止直接删除；普通清理默认进入回收站；AppData 项目还需要两次确认。

目前支持快速扫描、AppData 精确扫描、真实进度、双击打开目录、常见应用/开发缓存识别，以及 Windows 系统清理项说明。程序开源、免安装，不需要管理员权限。

如果你愿意试用，最希望得到的反馈是：哪些大目录没有被正确识别、用途说明是否准确，以及哪些操作仍然让人不放心。反馈截图和路径前请记得隐藏用户名等隐私信息。

## 知乎 / CSDN / 掘金长文提纲

1. 问题：AppData 为什么会越来越大。
2. 误区：名称包含 Cache/Temp 不代表可以无条件删除。
3. 36 GB 与 13 GB 的差异：快速估算、权限、链接、占用变化。
4. 设计原则：解释、默认不选、回收站、多重确认、系统路径保护。
5. 实现：PowerShell/WPF、后台扫描、进度通信、单文件打包。
6. 局限：无代码签名、不绕过权限、不处理系统组件存储。
7. 截图、下载地址与反馈邀请。

5. 双击打开实际目录：10 秒。

## 发布节奏

- 第 1 天：完善仓库首页、Topics、社交分享图和 Issue 模板。
- 第 2～3 天：发布一篇 AppData 容量差异科普文章。
- 第 4～7 天：发布一分钟演示视频，并在 V2EX/开发者社区分享。
- 后续版本：每个 Release 只发布一次变更摘要，避免重复刷屏。
